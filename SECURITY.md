# Security Policy

## Supported versions

Only the latest released `1.x` version receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead: **Security → Advisories → Report a vulnerability**
on this repository. That opens a private thread visible only to the maintainers.

Expect an initial response within a few days. If a fix is warranted it ships as a patch
release and is credited in the accompanying GitHub release notes.
